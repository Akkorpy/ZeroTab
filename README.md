ZeroTab is a simple and very minimalistic new tab that contains NASA API and provide its APODs.

## Description
Don't be scared of its functionality right now as it will be updated very soon (I guess). Try a modern and very minimalistic new tab page that ptovides informations about NASA's "a picture of the day".

## Features
- Search - Google search
- Shortcuts
- APOD section
